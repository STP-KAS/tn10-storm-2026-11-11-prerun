# Rules

The headmaster rule is [tn-master docs/NEURON.md](https://github.com/STP-KAS/tn-master/blob/main/docs/NEURON.md).

This repo is pre-run 1 of the Wednesday neuron. It is not that neuron. It is not Tuesday.

The operator arms the machine. He sends the matching paste. Until that send, the machine waits. One runner on the desk. One runner on Mini. One runner on the bot, and it sends payments only in the HOLD-4 minute.

The desk publishes [counts/desk/](counts/desk/README.md). Mini publishes [counts/mini/](counts/mini/README.md). The bot publishes [counts/bot/HOLD-4.md](counts/bot/README.md). Each machine writes only its own folder.

Before 2026-11-10T22:15:00Z the pastes hold. They do not send, and they do not wait in a process. The desk node stays up.

A fix that works is appended to [locks/LOCKED.md](locks/LOCKED.md). The pastes in this repo stay as they were at the arm. The next pre-run is a new repo and starts from that lock file.

Counts only. No key, seed, txid, covenant id, address, host, or port.

Call git by its full path. Empty output is a failed read. One commit per file. If the push fails, try once more, then stop and say the git error.
